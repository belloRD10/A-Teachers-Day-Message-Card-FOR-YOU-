# 🎉 A Teachers' Day Message Card – FOR YOU 💖

An interactive and animated **Teachers' Day Digital Message Card** created to express appreciation, gratitude, and heartfelt messages to teachers.

The project features animated greeting cards, 3D flip effects, floating emojis, raining decorations, confetti effects, popup messages, and background music—making it a fun and memorable digital Teachers' Day experience.

## ✨ System Features

### 💌 Interactive Teachers' Day Cards
- Multiple digital greeting cards.
- Each card contains a front and back section.
- Click **"Click Me 💌"** to reveal the personalized message.
- Smooth 3D card-flipping animation.
- **Back** button allows users to return to the front of the card.

The card interface uses CSS 3D transformations to create the flip effect.

### 🎊 Animated Confetti Effects
- Confetti is generated whenever a card is opened.
- Additional confetti appears after all cards have been opened.
- Creates a celebratory Teachers' Day experience.

The JavaScript generates multiple animated confetti elements whenever the flip action occurs.

### 🌈 Dynamic Background
The system automatically changes the page background using animated gradient combinations.

Available gradient themes include:
- Pink & Blue
- Peach & Pink
- Cyan & Rose
- Green & Light Green

The background automatically changes every **4 seconds**.

### 🎈 Floating Emojis
Animated emojis continuously float across the screen, including:

`🎉 💖 🎊 🌸 ⭐ 🍎 🎈 🌷`

The system randomly selects emojis, positions them across the screen, and applies different animation durations.

### 🌧️ Raining Emojis
The system also generates a continuous rain of celebratory emojis:

`💖 🌟 🌸 ✨ 💐 🎈`

These animated elements fall from the top of the screen to create a festive visual effect.

### 🎓 Animated Teacher-Themed Design
The cards use teacher and education-related visual elements such as:

- 👨‍🏫 Teacher
- 📚 Books
- 🎓 Graduation
- 🍎 Apple
- 🌷 Flowers
- 💖 Hearts

The HTML defines multiple Teachers' Day message cards with customized titles and messages.

### 🔔 Completion Popup
After all available cards have been opened, the system displays a special Teachers' Day popup
